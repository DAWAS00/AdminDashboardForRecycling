03 — Spacing

4pt Grid System

05 — Anti-Patterns

What to Fix (AI Slop Checklist)

These are the 10 specific patterns found in the current codebase that make the UI feel machine-generated. Fix these first before adding new features.

🚫 #1 — Raw hex colors inline on every element
Found 60+ instances of color: "#1E5C35", background: "#FEF3C7", etc. inline. Fix: Move all colors to CSS variables in :root or Tailwind tokens, then reference via var(--color-brand-600) or a Tailwind class. Three different "black" values are used: #1a1a1a, #1A1A1A, "black" — all should be --color-text-primary: #111827.
🚫 #2 — Font family repeated on every element
fontFamily: "'DM Sans',sans-serif" appears on ~60 individual elements. Fix: Set font-family: var(--font-sans) once on body in globals.css. Only override with --font-mono or --font-ar where needed.
🚫 #3 — Emoji used as a UI icon
In HeatMapPanel: "🔥 Rider hotspots" — emoji as a label prefix. Fix: Replace with a Lucide SVG icon (e.g. <Flame size={12} />) or remove entirely and use text only. Emojis are platform-dependent, unstyled, and inaccessible.
🚫 #4 — Eyeballed font size scale (9px → 10px → 11px → 12px → 13px)
The current scale has 6 sizes within a 4px range with no system. 9px text (BUILD 1.0.0) is below any accessibility floor. Fix: Use only the 7 sizes in this design system: 10, 11, 13, 14, 16, 18, 22, 28px. The 9px sidebar footer text should be removed or raised to 10px.
🚫 #5 — Inconsistent border-radius across similar elements
Badges use rounded-full, cards use rounded-xl (16px), some divs use rounded-lg (12px), inputs use rounded-lg but checkboxes are unstyled. Fix: Enforce the radius system: pills = --radius-full, chips = --radius-sm, cards = --radius-lg, buttons/inputs = --radius-md.
🚫 #6 — No focus states on interactive elements
All buttons/nav-items have transition-colors but zero focus styles. Tab-navigating the dashboard is invisible. Fix: Add :focus-visible { outline: 2px solid var(--color-brand-600); outline-offset: 2px; } globally, and use rgba(255,255,255,0.4) version for the dark sidebar.
🚫 #7 — No aria-labels on icon-only and non-obvious buttons
The X close button, chevron expand/collapse buttons, and checkbox toggles in HubsPanel have no accessible label. Fix: Add aria-label="Close rider detail", aria-label="Expand hub details", aria-label="Toggle hub active state".
🚫 #8 — Half-pixel spacing values (py-2.5, gap-1.5, mb-0.5)
Found py-2.5, gap-1.5, mb-0.5, gap-0.5, mt-0.5 throughout. These 2px/6px values break the 4pt grid. Fix: Round to nearest 4pt token. 2px → 0, 6px → 8px, 10px → 8px or 12px.
🚫 #9 — Right panel widths are different (284px vs 300px)
RiderPanel is 284px, HubsPanel is 300px, HeatMapPanel is 300px — they all occupy the same layout slot. Fix: Unify to --panel-width: 288px so the layout doesn't shift when switching views.
🚫 #10 — CO₂ & Reports views are blank placeholders
Two of the five nav items lead to a <PlaceholderView>. This makes the nav feel broken. Fix: Either hide these nav items until ready (and add them progressively), or build them — see ideas below.
06 — Feature Ideas

What to Build Next for Dawer

Ideas that fit the product's mission and fill the current gaps — ordered by impact and effort.

01
CO₂ Analytics View
The CO₂ Stats placeholder should become a real analytics panel. Show: daily/weekly CO₂ trend (area chart), breakdown by material type (donut chart), district contribution bar chart, and a "CO₂ equivalent" counter (trees saved, car-km offset). Use DM Mono for all numbers. Color per material type already defined.
High Impact · Medium Effort
02
Reports Export Panel
The Reports view should let admins export: rider performance table (orders, earnings, CO₂ per rider), hub shipment history, material collection summary by date range. Filters: date range picker, material type, district. Exports to CSV. Table has sortable columns with proper aria-sort.
High Impact · Medium Effort
03
Rider Assignment Flow
Currently, orders are pre-assigned. Add a drag-to-assign interface in the Live Map view: new orders appear in a queue on the right panel; admin drags them onto a rider card or clicks "Assign". Idle riders should pulse on the map as an affordance.
Medium Impact · High Effort
04
Hub Shipment Scheduler
The hubs panel has a "Schedule Shipment" button but no calendar. Add an inline mini-calendar (already imported with react-day-picker) to pick a date. Show upcoming shipments as a timeline strip below the hub list. Color-code: amber = scheduled, green = shipped, red = overdue.
Medium Impact · Low Effort
05
District Detail Drawer
When a district is selected on the Heat Map, slide in a drawer (not a panel) with: CO₂ potential vs achieved chart, top materials, recent orders in that district, and a "Boost Coverage" button that assigns an idle rider to the district. Drawer slides in from right over the map (uses react-resizable-panels already installed).
Medium Impact · Medium Effort
06
Global Search (⌘K)
A command palette that lets the admin search riders by name, order by ID, hub by district. cmdk is already installed. Press ⌘K or Ctrl+K to open. Results grouped by type. Selecting a rider opens their panel; selecting an order centers the map on it. This is the fastest way to navigate dense operational data.
High Impact · Low Effort
07
Notifications / Alert Feed
A bell icon in the header with a dropdown feed. Alerts: hub at 90% capacity, rider idle for 30min, order pending for 15min, shipment due today. Each alert has a 1-click action. Use sonner (already installed) for live toast alerts. Badge count on bell clears when opened.
High Impact · Low Effort
08
Dark Mode
next-themes is already installed. The sidebar's dark green (#06402B) becomes the base surface color. The main content area uses #0F1A14. Cards use #152219. This is a natural dark mode because the brand color IS dark. All token values need a dark-mode override — do not invert, use tonal variants.
Medium Impact · Medium Effort
07 — Rules of Thumb

Do / Don't for Dawer

✓ Do
Use var(--color-brand-600) everywhere you need the primary green.
✗ Don't
Write color: "#1E5C35" or color: "#166534" or color: "green" directly in a component.
✓ Do
Use Lucide icons (<Flame />, <Warehouse />) consistently at 14px or 16px.
✗ Don't
Use 🔥 or any emoji as a structural or navigation icon.
✓ Do
Label every icon-only button: aria-label="Close panel".
✗ Don't
Render a bare <X size={14} /> button with no accessible label.
✓ Do
All numbers, IDs, times, and monetary values use font-family: var(--font-mono).
✗ Don't
Mix DM Sans and DM Mono within the same stat or data field.
✓ Do
The right panel is always exactly --panel-width: 288px regardless of which view is active.
✗ Don't
Set RiderPanel to 284px and HubsPanel to 300px — the layout shift between views is jarring.
✓ Do
Use the MATERIAL_CONFIG object for all material colors — it's the single source of truth.
✗ Don't
Hardcode #1E40AF for plastic in a new component — use MATERIAL_CONFIG["Plastic Bottles"].color.
✓ Do
Empty/placeholder views show a meaningful state: icon + title + what's coming + ETA.
✗ Don't
Show "Charts and analytics coming soon" in the nav as a dead end with no context.
